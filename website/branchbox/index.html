The training recipe

Make stage and target explicit.

Two-object placement repeatedly changes the active object and its destination. BranchBox trains two small heads to predict the current stage and spatial target from pooled action-decoder features. The visual and language backbones stay frozen; auxiliary gradients update the action-decoder representation.

01 / Supervise

Stage + spatial target

Stage classification and continuous point or box regression share the decoder features used to generate robot actions.

02 / Perturb

Train with varied prompts

Stage text and a separate marked image provide intermediate cues. Independent prompt dropout and temporal perturbations vary those inputs during training.

03 / Deploy

Reuse the predictions

A supplied task-specific table maps predicted stages to text and mark types for the next query. The same trained policy can also run with ordinary inputs.

The task table supplies the decomposition. BranchBox predicts progress within that structure and target coordinates; it does not infer an open-ended task plan. The reported comparison evaluates the combined training recipe and deployment interface.

Paired evaluation

A focused view of multi-object placement.

SmolVLA and X-VLA are evaluated on the same 20 initial scenes for each of four tasks. Matched action-only training and BranchBox use the same training data within each model family. Both model families and all four tasks have positive success-rate point estimates in this analysis.

Retrospective, exploratory analysis of four two-object tasks and two model families. The evaluation uses 80 shared initial scenes, each evaluated with both models: 160 model–scene outcomes per deployment condition. Intervals resample the shared scenes and remain conditional on the selected tasks, models and one training seed; they are not adjusted for retrospective selection.
