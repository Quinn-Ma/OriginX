# Cue-precision studies

Paired studies that ask whether a more precise spatial cue, shown to the same frozen policy under the same frozen planner/verifier, changes placement success on RoboCasa365 `CoffeeSetupMug`. Each study is preregistered with fixed seed pairs, counterbalanced arm order, initial-state and natural-plan pairing admission, explicit UNKNOWN accounting and an offline analyzer frozen before execution. Results are reported as they are; no benchmark rank, no acceptance and no improvement claim is made from these studies.

## 1. regions-20261024 — done, no benefit

Registered rule (10 admissible pairs): fine-region 6/10 vs point 6/10; difference 0.0 percentage points, conservative 95% interval [-35.5, 35.5], exact paired McNemar p = 1.0; 0 region-only and 0 point-only successes. Deviation-inclusive analysis (11 pairs, including one case re-executed after a disclosed host interruption): point 7/11 vs fine-region 6/11; difference -9.1 percentage points, interval [-45.7, 32.7], p = 1.0; the whole difference comes from that one added pair. One further pair holds an UNKNOWN point-arm outcome (infrastructure timeout) and enters neither analysis. Neither analysis supports a success benefit from the region presentation, and the non-significant result does not establish equivalence. Anonymous paper, LaTeX sources, analyzer report, frozen manifest, scripts, audits and per-file SHA-256 digests are in [`regions-20261024/`](regions-20261024/); the 5 GB trace archive is kept offline and is available on request.

## 2. masks-20261027 — done, no benefit

Same frozen policy, planner and verifier. The cue is an exterior contour mask of the target object together with a subject-sized destination ghost box, drawn with supervision 0.27.0 `MaskAnnotator`. A preregistered 12-pair (24-case) run on seeds 20261044-20261055 and a 6-case engineering pilot on seeds 20261025-20261027 are registered, with a zero-sample policy-RGB rendering cohort registered for both arms. Rendering-fidelity checks passed the registered IoU >= 0.98 gate on an H800 and again on the H100 that ran the study (11/12 checks each; the stricter 1-pixel-band check flags the same 3 pixels in 1 of 117 masks on both).

The first pilot launch on a rented H800 (2026-10-26 23:06:50 UTC) was lost with the instance about 20 minutes later; no episode result was retrieved and nothing from it is counted. The study was then completed on the HKUST H100 cluster on 2026-10-27 with the same frozen sources, seeds, pairs, order and analyzer. **Registered rule (12/12 pairs admissible, 0 UNKNOWN): masks 5/12 vs point 8/12; 2 mask-only and 5 point-only successes; difference −25.0 percentage points, conservative 95% interval [−74.1, 39.7], exact paired McNemar p = 0.453.** No success benefit from exact contours was found; the point estimate favors the point cue; the non-significant result does not establish equivalence. Disclosed deviations: host change; two cluster GPUs excluded for corrupt depth readback; the manifests re-frozen with 3 workers (one per GPU) before any case completed, which changed the digest prefixes (pilot `df91a4d28570` → `7c89c95a12e7`, formal `94d4721e1452` → `8266cc633102`) but no seed, pair, order or arm; three launches that produced no episode, archived. Details, analyzer reports, re-frozen manifests, GPU probes, scripts and the disclosure note are in [`masks-20261027/hkust-20261027/`](masks-20261027/hkust-20261027/); the 9 GB trace archive is kept offline and is available on request.
