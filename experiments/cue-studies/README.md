# Cue-precision studies

Paired studies that ask whether a more precise spatial cue, shown to the same frozen policy under the same frozen planner/verifier, changes placement success on RoboCasa365 `CoffeeSetupMug`. Each study is preregistered with fixed seed pairs, counterbalanced arm order, initial-state and natural-plan pairing admission, explicit UNKNOWN accounting and an offline analyzer frozen before execution. Results are reported as they are; no benchmark rank, no acceptance and no improvement claim is made from these studies.

| Study | Cue under test | Design | Status | Folder |
|---|---|---|---|---|
| Fine-region cues (2026-10-24) | Local-region ("neighborhood") presentation vs the original exact destination point | 12 preregistered seed pairs (20261031-20261042), 24 slots | Done. No benefit found; equivalence not established. | [`regions-20261024/`](regions-20261024/) |
| Mask cues (2026-10) | Exterior contour mask of the target object plus a subject-sized destination ghost box (supervision 0.27.0 `MaskAnnotator`) vs the point cue | 12 preregistered seed pairs (20261044-20261055), 24 slots | Interface built; pixel fidelity verified on an H800 (11/12 checks); task outcomes **not measured** (compute exhausted, run not restarted). | [`masks-20261027/`](masks-20261027/) |

## 1. regions-20261024 — done, no benefit

Registered rule (10 admissible pairs): fine-region 6/10 vs point 6/10; difference 0.0 percentage points, conservative 95% interval [-35.5, 35.5], exact paired McNemar p = 1.0; 0 region-only and 0 point-only successes. Deviation-inclusive analysis (11 pairs, including one case re-executed after a disclosed host interruption): point 7/11 vs fine-region 6/11; difference -9.1 percentage points, interval [-45.7, 32.7], p = 1.0; the whole difference comes from that one added pair. One further pair holds an UNKNOWN point-arm outcome (infrastructure timeout) and enters neither analysis. Neither analysis supports a success benefit from the region presentation, and the non-significant result does not establish equivalence. Anonymous paper, LaTeX sources, analyzer report, frozen manifest, scripts, audits and per-file SHA-256 digests are in [`regions-20261024/`](regions-20261024/); the 5 GB trace archive is kept offline and is available on request.

## 2. masks-20261027 — task outcomes not measured

Same frozen policy, planner and verifier. The cue is an exterior contour mask of the target object together with a subject-sized destination ghost box, drawn with supervision 0.27.0 `MaskAnnotator`. A preregistered 12-pair (24-case) run on seeds 20261044-20261055 (manifest SHA-256 prefix `94d4721e1452`) and a 6-case engineering pilot on seeds 20261025-20261027 are registered, with a zero-sample policy-RGB rendering cohort registered for both arms. Rendering-fidelity checks passed the registered IoU >= 0.98 gate on an H800; one stricter 1-pixel-band check flagged 3 pixels in 1 of 117 masks. The 6-case engineering pilot was launched on the H800 at 2026-10-26 23:06:50 UTC and the instance became unreachable about 20 minutes later (compute budget exhausted); no episode result was retrieved, the 12-pair formal run was never started and the instance was not restarted. There are no mask task results to report. **Status: task outcomes not measured.** The anonymous CVPR 2027 submission that reports both studies (fine-region null result, verified mask interface, frozen protocol, outcomes not measured) is in [`masks-20261027/paper/`](masks-20261027/paper/) and [`../../paper/OriginX_Masks_CVPR2027_submission_v1.pdf`](../../paper/OriginX_Masks_CVPR2027_submission_v1.pdf); evidence, manifests, design documents, code snapshot and per-file SHA-256 digests are in [`masks-20261027/`](masks-20261027/). The study folder `masks-20261027/` will be added when there is something to report.
